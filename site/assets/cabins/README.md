# Фото срубов — «Суворовские Бани»

Сюда нужно положить реальные фотографии срубов (берутся из
[группы ВКонтакте](https://vk.com/suvorovskie_bani) или со съёмки).

Разметка сайта уже подключает эти файлы. Пока файла нет — карточка
показывает стилизованную заглушку (градиент), как только файл появится —
он автоматически подставится. Ничего в коде менять не нужно.

## Рекомендации к фото

- Соотношение сторон **4:3** (например, `1200×900` px)
- Формат `.jpg` (или `.webp` — тогда поправьте расширение в `index.html`)
- Вес до ~300 КБ (оптимизируйте, напр., squoosh.app)
- Горизонтальная ориентация, тёплый свет — под общую атмосферу сайта

> Цены и вместимость в карточках взяты из публичных источников
> (2ГИС / Яндекс / obiz) и могут отличаться — уточните у администратора.
